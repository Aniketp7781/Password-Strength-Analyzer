# Password Strength Analyzer

## Project Objective
This project evaluates password strength using security metrics and bcrypt hashing to improve credential protection.

## Features
- Password complexity analysis
- Entropy checking
- Character diversity analysis
- Secure bcrypt hashing
- Real-time feedback

## Tools Used
- Python
- bcrypt

## Security Concepts
- Password Security
- Hashing
- Brute Force Protection
- Dictionary Attack Prevention

## Future Improvements
- MFA Integration
- AI Password Suggestions
- Biometric Authentication
